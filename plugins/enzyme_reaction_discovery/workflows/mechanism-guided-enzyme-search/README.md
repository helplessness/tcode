# Mechanism-guided enzyme search

四阶段：输入净变化 → Wiki 类比或模型未核实的机制与辅因子 → 家族及路线比较 → 轻量批判与报告。

没有预置机制选项、固定化学评分或阶段内人工审核；完成后仍走宿主 R1 语义验收、证据门槛及必要的用户确认。第二阶段先检索摘要、按需读原始证据，并在提交时封存 02/03 真正引用的证据；第三阶段校验后直接继承这些片段，只针对具体候选、冲突和能力缺口有界补查。最终化由程序聚合已校验产物，不让模型复制大 JSON。

3.5.0 允许 Wiki 之外的机制和具体酶提议，固定标注“未经过 Wiki 核实”。没有具体酶的步骤使用 unmatched_capability，最终另列，不伪造蛋白实体。候选和路线可引用 proposal_id；只有 wiki_enzyme 才强制本酶已读 Wiki 引用。外部证据仍只来自 Wiki，不联网、不读历史记忆、不自动把提议写入知识库。

用户明确指定此 Workflow 才启动。默认前端只显示 user_summary；JSON 为内部格式，按需导出。Schema、实际文件、引用和幂等检查保留。参数错误允许有限修正；旧产物重做保存在 .history/，Wiki 变更须使用新 run。

首次只返回反应与检索协议，不注入预选知识卡。每阶段的新问题至多 3 批检索；第三阶段继承证据不占自己的新读取预算，未送达的上游证据才分批继承。仅已校验交接或本阶段实际读取的引用可提交。文本检索排名不代表化学可行性，未召回不代表全库不存在。来源支持的原生反应、机理假说和未核验注释分别呈现；未报道不等于不能催化。知识不足可给出空结果，候选分数不是实验成功概率。
