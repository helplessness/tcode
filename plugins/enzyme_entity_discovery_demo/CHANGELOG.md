# Changelog

## 0.17.1 - 2026-10-04

- 本体 Workflow 的运行时提示、阶段描述和插件元数据改为自包含协议，不再引用其他插件作为行为基准。
- 运行时统一使用本体实体、关系、Assertion 与 Evidence 术语，实体命中只改变证据状态，不自动决定候选排名。

## 0.17.0 - 2026-10-04

- 建立机制优先、候选冻结、证据核验和批判报告流程，并生成兼容的阶段投影产物。
- 保留原有运行产物，并新增兼容的 `02_mechanisms.json` 至 `07_final_report.*` 与 `mechanism_routes.mmd` 投影；不会迁移或覆盖历史运行。
- 本体查询契约显式保留支持/反对/未知、归属和版本化原文定位，并声明图命中及路线顺序不是科学适用性排名。

## 0.16.0 - 2026-09-21

- 本体与核心包升级至 0.4.0：明确酶变体的催化、辅因子与成员关系；新增参与通路和可能催化关系，禁止性质自动传播。
- 新不可变发布保留旧事实与数据库字节，提供兼容升级、校验、中断恢复和回滚。
- 抽取要求身份范围及实验/计算/文献转述/假设证据来源；未知或矛盾项进入明确审核。
- 模型一次纠正后仍不合法的关系进入可见隔离列表，不生成发布操作；有效片段继续处理。
- 真实论文全篇复测与原文抽查结果见“本体04升级与科学验收.md”，不将工程处理完成等同于科学审核通过。

## 0.15.1 - 2026-09-21

- 修复真实浏览器首次访问空 Workspace 时并发初始化 WAL 导致数据库锁错误；新增 8 线程并发首次打开回归。
- 名称匹配不再把 mg 等一至二字母歧义缩写自动解释为实体，保留完整名称匹配；抽取版本更新，旧作业不能混用续跑。
- 修正五项过时提示词测试，检查真实 Agent + Workflow 两层配置及通用科学边界。
- 完成隔离本机服务的登录、PDF 上传、审核发布、查询、报告、撤回和跨用户/Workspace 检查；真实模型科学验收仍待补。

## 0.15.0 - 2026-09-21

- 原有 Workflow 机制、候选和报告阶段开放 Workspace 分层查询；私有 Evidence ID 经宿主当前状态解析，保留引文、定位和来源。
- 每调用临时事实映射接入现有账本，不写公共库；候选查询仍须先冻结基线。
- 阻止把私有推测当成已报道事实，阻止负向断言支持候选，保守限制私有事实归属。
- 最终报告记录私有来源，重试、缓存答案展示与主聊天发送前复查撤回；失效证据不再以已验证结果交付。
- 新增三个固定抽取器集成场景，非真实 LLM 科学准确率测试。

## 0.14.0 - 2026-09-20

- 核心包 0.3.0 增加 Workspace 私有 SQLite、人工审核、独立发布、冲突、SQL 分页、撤回与引用复查。
- TCode 增加认证治理 API、“本体知识”页面及仅查询的每调用能力；Agent 无审核/发布接口。
- 插件移除共享 Workspace 重绑定，新加 workspace_query/workspace_report 工具；旧公共 Workflow 仍保留原合同。
- 增加私有库一致备份和新目录恢复命令；尚未完成真实论文科学验收、旧 Workflow 私有事实合同及企业公共治理。

## 0.13.0 - 2026-09-20

- 核心包 0.2.0 增加独立的文档草稿 CLI：import/inspect/run/retry/cancel。
- TXT/Markdown 行号与文字 PDF 页码/提取文本块定位；扫描件返回 ocr_required，不自动 OCR。
- 按作用域隔离原件哈希仓库，SQLite 持久化作业、文档与片段检查点，支持部分完成和重试。
- 候选经过结构、引文、端点和身份/冲突检查，生成待审操作流，不能进入正式事实查询。
- 支持仅实体提及模式与显式本机模型抽取；原论文/真实模型科学质量尚未验收。

## 0.12.0 - 2026-09-20

## 0.9.1 - 2026-09-15

## 0.9.0 - 2026-09-15
