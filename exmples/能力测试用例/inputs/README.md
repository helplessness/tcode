# 测试输入放置说明

请将文件复制到与 T 编号对应的子目录。文件名尽量使用英文、数字、短横线或下划线；测试本身仍需覆盖中文文件名和带空格路径时，可以额外保留一份原始命名样本。

复制完成后，建议在上一级创建一份本地登记文件：

```bash
cp 测试数据登记模板.yaml.example inputs/测试数据登记.local.yaml
```

然后填写文件名、已知事实、MCP 参数和预期产物。`inputs` 内所有内容默认被 Git 忽略。

不要放入：

- 真实 API Key、Cookie、Token 或私钥；
- 未脱敏的生产数据库；
- 没有使用许可的数据；
- 唯一副本。测试可能会修改、移动或生成旁路文件，重要数据必须另有备份。
